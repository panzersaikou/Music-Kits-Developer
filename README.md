# 音乐盒工坊

[打开在线音乐盒工坊](https://panzersaikou.github.io/Music-Kits-Developer/) · [下载离线工坊 ZIP](https://github.com/panzersaikou/Music-Kits-Developer/raw/refs/heads/gh-pages/music-kit-studio.zip)

模拟 CS2 音乐盒的场外音频制作与检视网页。在线制作台的「下载离线 HTML」可直接保存单个网页。也可以下载上面的 ZIP，解压后用浏览器打开里面的 `music-kit-studio.html`。

## 使用

1. 在制作台的素材库多选或拖入音频。每段素材有独立标签、播放位置和剪辑选区。
2. 在波形上拖动播放头试听，拖动两端的橙色手柄截取片段，也可以输入入点和出点。
3. 选择场景后点击「添加片段」。可以从不同素材反复添加，调整顺序，并拖动场景时间轴试听拼接结果。
4. 素材和精剪窗口均可放大至 64 倍。用波形上方的滑块平移视图，在精剪波形上拖动可重新选取片段。
5. MVP、回合胜利和回合失败默认在场景最后 1.5 秒淡出。在场景编排中可分别开启开头淡入和结尾淡出，设置各自的时长并试听。两段渐变的总时长超过场景长度时，会按比例缩短。
6. 打开「成品检视」，选择回合事件或 MVP 凯歌以试听最终编排。
7. 点击制作台上方的「导出预览 HTML」，下载当前音乐盒的独立检视页。文件自带已编排的场景音频、封面、背景和介绍，发给朋友后用浏览器打开即可离线试听。浏览器若拦截自动播放，点一次播放图标即可。若浏览器未自动下载，可点「保存刚导出的预览」手动保存。原始素材和可继续修改的工程仍保存在制作台中。

在仓库目录启动静态服务器。

```sh
python3 -m http.server 3000 --bind 0.0.0.0
```

打开 [localhost:3000](http://localhost:3000)。网页没有第三方运行时依赖。素材和场景编排保存在当前浏览器的 IndexedDB 中。请使用同一浏览器和同一站点地址恢复项目。单文件上限为 100 MB，可用格式取决于浏览器的解码支持。

## 场景参考

大厅、回合开始、回合行动、回合胜负、下包后音乐、十秒警告、死亡视角和 MVP 凯歌的触发说明，参考了 [GameTracking-CS2 收录的 CS2 游戏英文本地化文件](https://github.com/SteamDatabase/GameTracking-CS2/blob/master/game/csgo/pak01_dir/resource/csgo_english.txt)。网页将游戏音量设置里共用的回合结束类别拆为胜利和失败两条音轨，便于分别制作和试听。

## 成品检视

点击检视页右下角的「Movie」可从头连播已编排的场景。顺序为大厅、回合时间冻结、开始行动、阵亡、选择阵营、回合胜利、回合失败、下包后音乐的前 30 秒、十秒警告的最后 10 秒，最后依次播放已启用的 MVP 凯歌。短片段播到自身结尾。再次点击 Movie 可暂停或继续，旁边的图标可从头播放或停止。结束后恢复启动前的试听状态。新导出的预览 HTML 也包含 Movie。

在制作台的「音乐盒资料与封面」设置标题、封面、StatTrak™ 展示次数和作品介绍。MVP 凯歌可以编排一至三首。缩减数量后，已编排的备用凯歌会保留，调回数量即可继续编辑。

进入检视后默认循环主界面音乐。通过左下角的耳机按钮选择场景，场景播完会自动回到主界面音乐。若浏览器要求用户交互，可在底栏点播放。旁边的图片按钮可更换本地背景。

各场景仅提示推荐长度。下包后音乐推荐 40 秒，依据为 CS2 的 [mp_c4timer 默认配置](https://github.com/SteamDatabase/GameTracking-CS2/blob/master/DumpSource2/convars.txt)。先编排下包后音乐，十秒警告会使用其最后 10 秒。先编排十秒警告，下包后音乐会保留警告的结尾，向前取最多 40 秒。时长按实际播放速度计算，遇到素材开头就从头播放。自动片段可在工作台精剪，修改后独立保存，也可点击「恢复自动取段」重新联动。

## 工作台与混音

顶部可新建或切换工作台。首次成功导入音频时，文件名会成为默认名称，内嵌图片会成为封面。没有可读取图片的音频会显示名称封面。封面读取使用随页面打包的 music-metadata。

选中素材后可收起素材库。拖动全曲总览可跳到歌曲的任意位置，放大后可启用「平移」或按住 Shift 拖动主波形。素材倍速使用变速播放，音高随速度变化。素材、精剪片段与场景的音量按层相乘。素材旁的删除按钮可以移除当前工作台中的音频。若场景引用了这份素材，删除前会显示受影响的片段数量。检视底栏的耳机按钮用于选曲，悬停扬声器可调节总音量。

检视时可按住唱片并拖动观察封套与黑胶的透视变化，松手后回到轻微摆动。系统开启「减少动态效果」时仅保留手动旋转。底部图片按钮可选择地图、默认庭院或上传自定义背景，选择随工作台保存。内置地图截图来自 [GhostCap 的 CS2 地图图库](https://github.com/ghostcap-gaming/cs2-map-images/tree/2b24f0bef2977698a168a1b52c8e2f50fcbf32e3/cs2)。
